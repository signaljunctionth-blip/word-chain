# คำต้องเชื่อม

เกมผลัดกันตอบคำนามภาษาไทยที่ความหมายเชื่อมกับคำก่อนหน้า เช่น ทะเล → ปลา → ตลาด → เงิน
เล่นในเครื่องเดียวกันได้ทันที และเล่นออนไลน์กับเพื่อนได้เมื่อเชื่อม Firebase แล้ว
มีคลังคำในเกมกว่า 400 คำ เพิ่มคู่คำเองและตรวจคำได้ที่หัวข้อ “คลังคำ” ในหน้าแรก

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | ตัวเกมทั้งหมด |
| `firebase-config.js` | ค่าการเชื่อมต่อ Firebase (ว่างไว้ = เล่นได้เฉพาะในเครื่อง) |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล ใช้ตอนตั้งค่า Firebase |
| `README.md` | คู่มือนี้ |

## ส่วนที่ 1: ขึ้นเว็บด้วย GitHub Pages (เล่นในเครื่องได้เลย)

1. เข้า [github.com](https://github.com) แล้วล็อกอิน กด **New repository**
2. ตั้งชื่อ เช่น `word-chain` เลือก **Public** แล้วกด **Create repository**
3. ในหน้า repository กด **uploading an existing file** แล้วลากทั้ง 4 ไฟล์ในโฟลเดอร์นี้ไปวาง กด **Commit changes**
4. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** โฟลเดอร์ **/ (root)** แล้วกด **Save**
5. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/word-chain/`

เปิดลิงก์นี้แล้วเล่นในเครื่องได้ทันที ไม่ต้องล็อกอิน
กรรมการในเวอร์ชันนี้ใช้คลังคำในเกม (ไม่มี Claude) คำที่ไม่อยู่ในคลังจะไม่ผ่าน

## ส่วนที่ 2: เปิดโหมดออนไลน์ด้วย Firebase (ฟรี)

### 2.1 สร้างโปรเจกต์
1. เข้า [console.firebase.google.com](https://console.firebase.google.com) ล็อกอินด้วยบัญชี Google
2. กด **Create a project** ตั้งชื่อ เช่น `word-chain` (ปิด Google Analytics ได้) แล้วกดสร้าง

### 2.2 เปิดการล็อกอินแบบไม่ระบุตัวตน
เพื่อนจะเข้าเล่นได้โดยไม่ต้องสมัครอะไร
1. เมนูซ้าย **Build → Authentication** กด **Get started**
2. แท็บ **Sign-in method** เลือก **Anonymous** แล้วเปิด **Enable** กด **Save**
3. แท็บ **Settings → Authorized domains** กด **Add domain** แล้วใส่ `ชื่อผู้ใช้.github.io`

### 2.3 สร้างฐานข้อมูล
1. เมนูซ้าย **Build → Firestore Database** กด **Create database**
2. Location เลือก **asia-southeast1 (Singapore)** เพื่อให้เร็วในไทย
3. เลือก **Start in production mode** แล้วกดสร้าง
4. แท็บ **Rules** ลบของเดิม วางเนื้อหาจากไฟล์ `firestore.rules` ทั้งหมด แล้วกด **Publish**

### 2.4 คัดลอกค่าการเชื่อมต่อมาใส่เกม
1. กดรูปเฟือง **Project settings** มุมซ้ายบน
2. เลื่อนลงไปที่ **Your apps** กดไอคอน **</>** (Web) ตั้งชื่อแอป แล้วกด **Register app** (ไม่ต้องติ๊ก Hosting)
3. จะเห็นโค้ด `const firebaseConfig = { ... }` ให้คัดลอกเฉพาะส่วน `{ ... }`
4. ใน GitHub เปิดไฟล์ `firebase-config.js` กดรูปดินสอเพื่อแก้ไข แล้วเปลี่ยน

   ```js
   window.FIREBASE_CONFIG = null;
   ```

   เป็น

   ```js
   window.FIREBASE_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." };
   ```

5. กด **Commit changes** รอ 1–2 นาทีให้ GitHub Pages อัปเดต

### 2.5 เล่นกับเพื่อน
1. เปิดเว็บเกม เลือก **ออนไลน์กับเพื่อน** ใส่ชื่อ แล้วกด **สร้างห้องใหม่**
2. ให้เพื่อนสแกน QR ในหน้าห้องด้วยกล้องมือถือ หรือส่งรหัสห้อง 4 ตัวให้เพื่อนกรอก
3. มีผู้เล่นตั้งแต่ 2 คน เจ้าของห้องกด **เริ่มเกม**

## คำถามที่พบบ่อย

- **ค่าใน firebase-config.js เป็นความลับไหม**
  ไม่ใช่ เปิดเผยบน GitHub ได้ตามปกติของ Firebase ความปลอดภัยมาจากกฎใน `firestore.rules`
- **เสียเงินไหม**
  แพ็กเกจฟรี (Spark) อ่านได้ 50,000 ครั้ง และเขียนได้ 20,000 ครั้งต่อวัน เพียงพอสำหรับเล่นกับเพื่อนหลายสิบเกมต่อวัน
- **ขึ้นว่า "บันทึกข้อมูลห้องไม่ได้"**
  ตรวจว่าวางกฎจาก `firestore.rules` แล้วกด Publish และเปิด Anonymous ในข้อ 2.2 แล้ว
- **ขึ้นว่า "โหมดออนไลน์ยังไม่เปิด"**
  ยังไม่ได้ใส่ค่าใน `firebase-config.js` หรือ GitHub Pages ยังอัปเดตไม่เสร็จ ลองรีเฟรชหลังรอสักครู่
- **ล็อกอินด้วยอีเมลหรือ Google ได้ไหม**
  ได้ ต้องเพิ่มวิธีล็อกอินใน Authentication และปรับโค้ดเล็กน้อย ตอนนี้ใช้แบบไม่ระบุตัวตนเพื่อให้เพื่อนสแกน QR แล้วเล่นได้ทันที
